Set up Hypothesis

How Hypothesis works in this tool

This tool uses Hypothesis groups for document annotations.

  • Model Predictions group: lets you view annotations created by the model.
  • Project review group: where reviewers add corrections, rejections, and new annotations.
  • Gold annotations group: used only by admins or judges.

Important: Do not annotate in the Model Predictions group

The Model Predictions group is for viewing model-generated annotations only. Do not create, edit, reply to, or delete annotations in this group.

Adding human annotations to the Model Predictions group may contaminate the model annotation layer and affect downstream review, syncing, and data extraction.

Before adding any annotation or reply, switch Hypothesis to the project review group.

Step 1 — Log in to Hypothesis

Log in to Hypothesis using the account you will use for this project.

Log in to Hypothesis Create Hypothesis account

Step 2 — Install Hypothesis in your browser

Do not rely on old Via-style links. Use the official browser extension or bookmarklet instead.

Install Chrome Extension Install Bookmarklet for Firefox, Safari, Edge, or other browsers

After installation, open a document in this tool, activate Hypothesis from your browser, and choose the correct Hypothesis group in the sidebar before annotating.

Model Predictions

Model predictions are managed by the app and should be treated as read-only reference annotations. Users should not annotate in the Model Predictions group.

For review work, use the project review group.

{% if user.role == "admin" %} Admin only: Open Model Predictions Group {% endif %}

Step 4 — Create or join the project review group

Create one private Hypothesis group for the project and invite the reviewers plus the server Hypothesis account. This keeps the project review separate from the original model and gold annotation groups.

Create Private Hypothesis Group

After creating the group, copy the group link and set it as the project review group in this tool.

Step 5 — Check the project review group

Confirm that the selected project has a review group and that the server account can access it.

Check Project Review Group

Step 6 — Start coding documents

Go to Search Documents, open a document, activate Hypothesis in your browser, and select the project review group in the Hypothesis sidebar before adding annotations.

Go to Search Documents
