Set up Hypothesis

How Hypothesis works in this tool

This tool uses Hypothesis groups for document annotations. Most projects use the shared review group; a separate private group is needed only for restricted projects.

  • Shared review group: where reviewers see copied suggestions and add corrections, rejections, and new annotations.
  • Restricted review group: optional separate group for projects with limited membership.

Step 1 — Install Hypothesis in your browser

Do not rely on old Via-style links. Use the official browser extension or bookmarklet instead.

Install Chrome Extension Install Bookmarklet for Firefox, Safari, Edge, or other browsers

After installation, open a document in this tool, activate Hypothesis from your browser, and choose the shared review group in the sidebar before annotating.

Step 2 — Log in to Hypothesis

Log in to Hypothesis using the account you will use for this project.

If login does not work on a National Archives judgment page, open google.com, activate the Hypothesis extension there, log in to Hypothesis, then return to the judgment page and choose the project review group.

Step 3 — Join the review group once

Most projects use one reusable shared review group. Reviewers join it once, then day-to-day review happens from document pages. The app separates project work using project and document tags. Create a separate private group only for restricted projects or teams.

After reviewers join in Hypothesis, they should request app review access with their Hypothesis username. Admins approve requests in the review group settings before annotations are imported during sync.

Reviewers can find their Hypothesis username in their Hypothesis account/profile. They only need to provide the username, for example alice; the app stores it as acct:alice@hypothes.is.
