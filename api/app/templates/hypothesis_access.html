Set up Hypothesis

How Hypothesis works in this tool

This tool uses Hypothesis groups for document annotations. Most projects use the shared review group; a separate private group is needed only for restricted projects.

  • Model Predictions group: lets you view annotations created by the model.
  • Shared review group: where reviewers add corrections, rejections, and new annotations for collaborative projects.
  • Gold annotations group: used only by admins or judges.

Important: Do not annotate in the Model Predictions group

The Model Predictions group is for viewing model-generated annotations only. Do not create, edit, reply to, or delete annotations in this group.

Adding human annotations to the Model Predictions group may contaminate the model annotation layer and affect downstream review, syncing, and data extraction.

Before adding any annotation or reply, switch Hypothesis to the shared review group selected for the project.

Model Predictions

Model predictions are managed by the app and should be treated as read-only reference annotations. Users should not annotate in the Model Predictions group.

For review work, use the shared review group selected for the project.

Step 4 — Join the shared review group

Most projects use one reusable shared review group. Reviewers join it once, and the app separates project work using project and document tags. Create a separate private group only for restricted projects or teams.

Create Separate Private Group

If a separate group is needed, copy the group link and set it as the project review group in this tool.

Step 5 — Check the selected review group

Confirm that the selected project has a review group and that the server account can access it. For collaborative review, this is normally the shared review group.
