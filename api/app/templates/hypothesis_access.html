Set up Hypothesis

How Hypothesis works in this tool

This tool uses Hypothesis groups for document annotations. Most projects use the shared review group; a separate private group is needed only for restricted projects.

  • Shared review group: where reviewers see copied suggestions and add corrections, rejections, and new annotations.
  • Restricted review group: optional separate group for projects with limited membership.

Step 1 — Log in to Hypothesis

Log in to Hypothesis using the account you will use for this project.

Log in to Hypothesis Create Hypothesis account

Step 2 — Install Hypothesis in your browser

Do not rely on old Via-style links. Use the official browser extension or bookmarklet instead.

Install Chrome Extension Install Bookmarklet for Firefox, Safari, Edge, or other browsers

After installation, open a document in this tool, activate Hypothesis from your browser, and choose the shared review group in the sidebar before annotating.

Step 3 — Join the shared review group

Most projects use one reusable shared review group. Reviewers join it once, and the app separates project work using project and document tags. Create a separate private group only for restricted projects or teams.

Create Separate Private Group

If a separate group is needed, copy the group link and set it as the project review group in this tool.

Step 4 — Check the selected review group

Confirm that the selected project has a review group and that the server account can access it. For collaborative review, this is normally the shared review group.

Check Project Review Group

Step 5 — Start reviewing documents

Go to Search Documents, open a document, activate Hypothesis in your browser, and select the shared review group in the Hypothesis sidebar before adding annotations.

Go to Search Documents
